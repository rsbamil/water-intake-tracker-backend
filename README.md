# Water Intake Tracker - Backend

Backend API for the Water Intake Tracker application.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

## Current Features

- Express server setup
- MongoDB connection
- User schema
- Intake log schema
- User-to-intake relationship
- Environment-based configuration
- Health check API
- Global error handling
